# Student Task & Assignment Manager

A beginner-friendly front-end project built with HTML, CSS and vanilla JavaScript.

## Features
- Add tasks with subject, due date and priority
- Edit and delete tasks
- Mark tasks as completed
- Search by task title or subject
- Filter pending and completed tasks
- Dashboard counts for total, pending and completed tasks
- Save tasks in browser Local Storage
- Responsive layout for mobile and desktop

## Run the project
1. Extract the project folder.
2. Open `index.html` in a web browser.
3. Add a task using the form.
4. Refresh the page to confirm that tasks remain saved.

No server or external library is required.
